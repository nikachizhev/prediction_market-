# Задачи MVP Mini App

Ведёт агент-оркестратор. Ветка интеграции — `miniapp`, задачи — `miniapp-<эпик>-<коротко>`.
MVP = E1–E5 + минимум бота (кнопка «Открыть приложение», разрешение рынка с фото, сообщение о выплате) + таблица событий.

## Технические решения (для всех задач)

- **API** — обычные Django-вьюхи с JSON (`market/api/`), без DRF/Ninja: не нужна новая зависимость, эндпоинтов немного.
- **Авторизация API** — каждый запрос несёт заголовок `Authorization: tma <initData>`; сервер проверяет HMAC ключом бота и `auth_date` (не старше 24 ч). Без сессий и cookie: WebView Telegram и третьи cookie не дружат, CSRF не нужен.
- **Telegram ID** = `Trader.telegram_chat_id` (в личном чате chat_id совпадает с user id) — один аккаунт на Telegram ID.
- **История операций** — новая модель `LedgerEntry` (вид, сумма со знаком, рынок). Каждое изменение баланса в `services.py` пишет запись.
- **Комиссия 2%** удерживается из суммы покупки (как `quote()` в макете `Main.dc.html`) и из выручки при продаже. Копится в рынке (`Question.fee_pool`); при итоге половина — создателю, половина сгорает; при отмене участникам возвращается всё вложенное, комиссия тоже. В «Моих» у открытого рынка создателю показываем ожидаемую комиссию.
- **Субсидия создания** 100 монет уходит в рынок. При итоге: остаток пула (субсидия + чистые вложения − выплаты), но не больше 100, возвращается создателю; сверх 100 сгорает.
- **Фото-доказательства** — `FileField` в медиа Django (без Pillow).
- **Фоновые задачи** — management-команда `run_worker` (цикл раз в минуту), без Celery/Redis.
- **Фронтенд** — `miniapp/`: React 18 + Vite 5 (Node 18 на машине) + TypeScript, `react-router-dom`. Telegram SDK — официальный скрипт `telegram-web-app.js`, без npm-пакета. Графики — свой SVG (мини-график, линия с периодами), без библиотеки.
- **Локальная разработка без Telegram** — команда `make_init_data` подписывает тестовый `initData` токеном бота из `.env`; фронт берёт его из `VITE_DEV_INIT_DATA`. Неподписанный ID сервер по-прежнему не принимает.

## Ответы на открытые вопросы спеки

Решено пользователем 25.10.2026:

- **Кто создаёт рынки** — любой пользователь сразу (без порога в 5 прогнозов); спам сдерживают стоимость 100 и лимит 3 рынка в день.
- **Комиссия при отмене рынка** — возвращается полностью: комиссия держится в рынке до итога.
- **Продажа до итога** — есть в MVP; комиссия 2% берётся и с продажи.
- **Споры** решает команда в админке Django.
- **Запрещённые темы** — здоровье и смерть конкретных людей, насилие, политика, личная жизнь других пользователей (текст правил в мастере создания + жалобы).
- **Telegram Stars** — монеты не продаём.
- **Фронтенд** — React.
- **Закрытый чат** — фаза 3; **дашборд** — для команды, фаза 2.
