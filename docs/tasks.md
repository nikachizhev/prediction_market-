# Задачи MVP Mini App

Ведёт агент-оркестратор. Ветка интеграции — `main` (с 28.10.2026; до этого была `miniapp`, задачи до T15 сливались в неё), задачи — `<эпик>-<коротко>` от `main`.
MVP = E1–E5 + минимум бота (кнопка «Открыть приложение», разрешение рынка с фото, сообщение о выплате) + таблица событий.

## Технические решения (для всех задач)

- **API** — обычные Django-вьюхи с JSON (`market/api/`), без DRF/Ninja: не нужна новая зависимость, эндпоинтов немного.
- **Авторизация API** — каждый запрос несёт заголовок `Authorization: tma <initData>`; сервер проверяет HMAC ключом бота и `auth_date` (не старше 24 ч). Без сессий и cookie: WebView Telegram и третьи cookie не дружат, CSRF не нужен.
- **Telegram ID** = `Trader.telegram_chat_id` (в личном чате chat_id совпадает с user id) — один аккаунт на Telegram ID.
- **История операций** — новая модель `LedgerEntry` (вид, сумма со знаком, рынок). Каждое изменение баланса в `services.py` пишет запись.
- **Комиссия 2%** удерживается из суммы покупки (как `quote()` в макете `Main.dc.html`) и из выручки при продаже. Копится в рынке (`Question.fee_pool`); при итоге половина — создателю, половина сгорает; при отмене участникам возвращается всё вложенное, комиссия тоже. В «Моих» у открытого рынка создателю показываем ожидаемую комиссию.
- **Субсидия создания** 100 монет уходит в рынок. При итоге: остаток пула (субсидия + чистые вложения − выплаты), но не больше 100, возвращается создателю; сверх 100 сгорает.
- **Фото-доказательства** — `FileField` в медиа Django (без Pillow).
- **Фоновые задачи** — management-команда `run_worker` (цикл раз в минуту), без Celery/Redis.
- **Фронтенд** — `miniapp/`: React 18 + Vite 5 (Node 18 на машине) + TypeScript, `react-router-dom`. Telegram SDK — официальный скрипт `telegram-web-app.js`, без npm-пакета. Графики — свой SVG (мини-график, линия с периодами), без библиотеки.
- **Локальная разработка без Telegram** — команда `make_init_data` подписывает тестовый `initData` токеном бота из `.env`; фронт берёт его из `VITE_DEV_INIT_DATA`. Неподписанный ID сервер по-прежнему не принимает.

- **Отмена рынка** возвращает каждому чистое вложение (покупки с комиссией минус выручка от продаж). Кто продал с прибылью, её сохраняет; разницу сначала покрывает субсидия создателя, потом возвраты уменьшаются пропорционально — рынок не печатает монеты.
- **Лимит 500 на рынок** считается по себестоимости текущей позиции (`Position.spent`): продажа освобождает место. Списание себестоимости при продаже округляется вверх.
- **Бонус дня** в день регистрации не начисляется — первый день покрыт стартовым пакетом.
- **Страховка** не выдаётся, пока у человека есть позиции или собственный незавершённый рынок (его субсидия ещё вернётся).
- **`make_init_data`** подписывает данные токеном из `.env` — для разработки нужен отдельный тестовый бот, не боевой.

Решения фазы 2:

- **Награда за друга** — когда друг купил в 5 разных рынках, обоим по 300 (`LedgerEntry` «Награда за друга», в прибыль не входит). Лимит 10 наград в календарный месяц (МСК) у пригласившего; сверх лимита награды нет никому — иначе фермам выгодно.
- **Уведомления** идут через очередь `BotMessage`, воркер отправляет. В приложении («Уведомления») видно всё; настройки решают только, что пришлёт бот. Лимит 5 в день считает все типы, но итог и выплату не отбрасывает. Тихие часы 23:00–09:00 МСК: сообщение ждёт 09:00. Сверх лимита необязательные уведомления пропускаются, а не копятся. Вопрос создателю «Чем закончилось?» и напоминания — часть разрешения рынка, их настройки не выключают.
- **Анимация** рендерится в процессе бота по запросу и кэшируется на рынок и час; если ffmpeg нет — бот отвечает текстом.

- **«Получено» в приглашениях** — только награды за приглашённых мной друзей, без моей собственной награды как приглашённого.
- **Metabase** запускается профилем: `docker compose --profile metabase up -d`; обычный `docker compose up` его не трогает.

- **Нет ключа или `ASSIST_ENABLED=false`** — `Me.assist.enabled = false`, карточки помощника нет, остальное работает.
- **Категория «Погода» убрана** 28.10.2026: миграция переносит её рынки в «Фан» и чистит интересы.
- **Лимит помощника** (T16) — по событиям `assist_request` за московский день: считаются `ok`, `warning`, `error` (запрос дошёл до модели), отказы по лимиту (`limit`) не считаются. Выключенный помощник (503) событие не пишет. Счётчик — `market/assist.py` (`left`, `state`).
- **Ответ модели с недопустимыми датами** (приём меньше часа или больше года, итог раньше приёма) — отказ помощника (503, `error`), как ответ не по схеме: мастер работает без подсказки.
- **`assist` и `template` в `POST /api/markets`** — только аналитика: неизвестное значение отбрасывается, рынок создаётся как обычно.
- **«Время итога»** (поле из PR #27, в макете quick-create его нет) остаётся: помощник при «готово» ставит дату и время итога из `resolves_at`, шаблон — 23:59 на следующий день после `{date}`; «Вернуть как было» возвращает и время.
- **В тестах `LLM_API_KEY` пустой** (`config/test_settings.py`, `config/postgres_test_settings.py`): ключ из `.env` разработчика не включит настоящий запрос к модели.
- **Итог фазы 3a (28.10.2026)** — ветки `e9-base`, `e9-templates`, `e9-assist`, `e9-miniapp` слиты в `main`, не запушены. Проверено на настоящей модели (OpenRouter, `deepseek/deepseek-v4.1-flash`): ответ за 1–2 с, уточнение «в понедельник» → «в понедельник, 2 ноября», запрещённые темы `health` и `private` распознаются; в браузере на временной базе — шаблон, помощник, создание рынка с `assist: "accepted"` в `market_create`.
- **Чтобы помощник заработал на проде** — `LLM_API_KEY` в `.env` сервера (кладёт пользователь), затем рестарт `pm-web`. Без ключа мастер работает без карточки помощника.
- **Тексты вне макета — показать пользователю:** «Похоже, это рынок о насилии», «…о политике», «…о личной жизни другого человека» (о здоровье — из макета); «Помощник сейчас не отвечает — заполни правила сам.» (503); «Подсказки на сегодня закончились — их 20 в день.» (429); «Вопрос — от 10 до 120 символов.» (400). Mini App показывает тексты макета, кроме заголовка запрета — он с сервера.
- **Известные ограничения:** вопрос «…сегодня» даёт приём «до 23:59 вчера» — помощник отказывает (`dates`), мастер работает без подсказки; «Их 20 в день» в Mini App — константа (лимита нет в `Me.assist`); похожие рынки считают общими и неизменные слова шаблона («Сдам ли физику…» похож на «Сдам ли матанализ…»); скрытые из ленты рынки в похожих остаются.
