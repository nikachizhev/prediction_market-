Здесь лежат исходники тех же экранов в формате `.dc.html` (Design canvas). Отдельно в браузере они не запускаются — это **справочник** для реализации: разметка, отступы, тексты интерфейса, цвета и поведение.

| Файл | Экран |
| --- | --- |
| `Onboarding.dc.html` | Первый вход: приветствие → первый прогноз за 3 нажатия → персонализация |
| `Main.dc.html` | Лента рынков + панель прогноза (bottom sheet) |
| `Dark.dc.html` | Та же лента в тёмной теме |

| `Mine.dc.html` | Мои: позиции, отслеживаемые, созданные рынки |
| `Create.dc.html` | Мастер создания рынка из 3 шагов |
| `Rating.dc.html` | Рейтинг: все/друзья, прибыль/точность, периоды |
| `Profile.dc.html` | Профиль, график баланса, калибровка, приглашения |

| `Chat.dc.html` | Пространство закрытого чата |

| `TabBar.dc.html` | Компонент нижних вкладок |

Как читать файл:

- Цветовые токены светлой и тёмной темы — в методе `theme()` внутри `<script data-dc-script>`. Это и есть палитра продукта.
- Расчёт выплаты в панели прогноза (`quote()`) повторяет LMSR из спеки: b = 144, комиссия 2% удерживается со ставки, лимит сделки 20% баланса и не больше 200. На бэкенде правда одна — `market/services.py`; макет только показывает, как это выглядит.
- Тексты интерфейса берём из макетов дословно, если задача не говорит иначе.
- Данные в макетах (рынки, имена, цифры) — примеры, не фикстуры.
